# Credit Card Validator

A simple C++ program that validates credit card numbers using the Luhn Algorithm.

## How It Works

The program:

* Processes the digits using the Luhn algorithm.
* Calculates the checksum.
* Checks if the result is divisible by 10.

## Run

```bash
g++ main.cpp -o validator
./validator
```

## Example

```text
give me ur credit card num: 4532015112830366
valid
```

This project was created for practicing basic C++ concepts such as functions, loops, strings, and conditionals.
